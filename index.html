Настройки семьи

Члены семьи

Автоматический расчёт только для взрослых 18–100 лет. Для детей, беременности и особых медицинских потребностей задайте согласованную со специалистом норму вручную. Данные не отправляются на сервер.

Кухонная техника

Общие исключения

Отметьте продукты для всей семьи. Для аллергии исключайте также производные продукты и проверяйте маркировку, следы и перекрёстное загрязнение. Это не медицинская система проверки аллергенов.

Продукты дома

Введите остатки в граммах съедобной части: очищенные овощи, яйца без скорлупы, сухая крупа. Для консервов — без жидкости. Значения прежней версии сохранены. Они будут вычтены из покупок. Проверьте сроки годности.

Каталог и цены

Цены обычных магазинов сохраняются отдельно для каждого города. Вводите итоговую цену за упаковку с применимой скидкой по карте; условия и дату указывайте в примечании. Персональные купоны не рассчитываются автоматически.

Цены за упаковку в рублях. Внесите фактические цены и вес продукта до очистки (для яиц — число штук в упаковке; для фасоли — масса без жидкости). Ноль в цене означает, что товар недоступен. Укажите адрес, дату и условия акции в примечании. Акции можно загрузить кнопкой ниже; ручные цены сохраняют приоритет.

Массовый импорт цен (CSV)

Скачайте шаблон, заполните цены из каталога магазина и вставьте содержимое сюда. Разделитель — точка с запятой. Пустые цены пропускаются; 0 означает отсутствие товара. Для яиц укажите число штук и текущую категорию. Импорт применяется только к выбранному магазину и профилю.
